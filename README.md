# Chord Progression Web Audio Player

## 概要
メジャー/マイナーコードボタンをクリックして進行を作成し、Web Audio APIでオシレーター合成（サイン波3和音）でBPMを設定してループ再生できる音楽制作ツール。

## 機能
- 16種類のコードパレット（C, Dm, Em, F, G, Am等）
- 最大8コードの進行作成
- Web Audio APIによるサイン波合成
- BPMスライダー
- ループ再生・停止
- 再生中のコードハイライト
- プリセット（I-IV-V-I、ポップ、ジャズii-V-I、12バーブルース）

## 使い方
コードパレットのボタンをクリックして進行を作成します（最大8コード）。BPMを設定して「Play」ボタンを押すと再生します。「Loop」ボタンでループを切替えられます。プリセットボタンで有名な進行をすぐに試せます。
